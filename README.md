# science.rayanupadhyay.com

Rayan Upadhyay's Games: 69 free browser games, no downloads.

**Live:** [science.rayanupadhyay.com](https://science.rayanupadhyay.com)

## Features

- Games sorted into Arcade, 3D Games, Pixel Games, Henry Stickmin, and Flash Classics
- Search and category filters
- Recently played list, saved on your device
- Fullscreen and open-in-new-tab buttons
- Every game has its own link, like `science.rayanupadhyay.com/#slope`

## Credits

The game collection comes from [Gams](https://github.com/Gams-Offline/Gams) by mountain658. Flash games run on [Ruffle](https://ruffle.rs). All games belong to their original creators.

The homepage (`index.html`) was redesigned for this site. The games themselves live in the `g/` and `img/` folders.
